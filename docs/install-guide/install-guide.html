Good to know
Don't see the option on iPhone?

Make sure you're in Safari, not inside another app's browser (e.g. a link opened from Instagram or Messenger). Open Safari and type logbook.fit yourself.

Using Samsung Internet?

Tap the ☰ menu → Add page to → Home screen.

Do I need to log in again?

Only the first time you open it from the icon — after that you'll stay signed in as usual.

Want it gone?

Press and hold the icon and remove it, like any app. Your account and training data are untouched.
